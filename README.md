# 偏偏是金善旴

一个关于熟悉、偏爱，以及某只特别傲娇的小浣熊的互动故事。

## 在线体验

https://sunwoo-story.app.workbuddy.host/?sharecode=RSQ7MXUDHV

## 关于

单文件互动剧情游戏，所有图片、音乐、语音均已内嵌在 `index.html` 中，无需任何额外依赖。

- 三首 BGM 轮播（Still Love You / The Season / Together Forever）
- 可调节音量、可暂停续播
- 标题界面可自定义女主名字
- 适配手机竖屏

## 本地运行

直接用浏览器打开 `index.html` 即可。
